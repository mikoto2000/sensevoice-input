# SenseVoice Input

Windows 11 x64 向けの、日本語を音声で入力するアプリです。キーを押している間だけ録音する「PTT」と、声を検知して録音する「自動入力」を利用できます。音声認識には Whisper、声の検知には Silero VAD を使用します。

モデルなどの初回ダウンロード後は、オフラインで動作します。

## 導入

### 必要なもの

- Windows 11 x64
- .NET Desktop Runtime 10 x64
- マイク
- 初回ダウンロード用のインターネット接続と空き容量（Whisper モデルは約1.62 GB。GPU 用ファイルは別途必要です）
- GPU を使う場合は、対応する NVIDIA GPU とドライバー

NVIDIA GPU を使わない場合は、設定の **Execution Provider** で **CPU** を選択してください。Python や .NET SDK のインストールは不要です。

### 起動と初期設定

1. 配布 ZIP をフォルダーに展開し、`SenseVoiceInput.App.exe` を起動します。
2. 設定画面でマイクを選び、**Execution Provider** を **CUDA**（NVIDIA GPU）または **CPU** に設定して保存します。設定画面が見えない場合は、通知領域のアイコンをダブルクリックしてください。
3. 必要なモデルのダウンロードが完了するまで待ちます。進捗は設定画面で確認でき、中止・再試行もできます。
4. PTT または自動入力に使うキーを設定し、保存します。

初期設定は CUDA です。GPU 用ファイルが不足している場合は NVIDIA の利用条件を表示し、同意後に取得します。CPU の場合は取得しません。NVIDIA ドライバーは自動インストールされません。

モデルと GPU 用ファイルの準備が完了するまでは音声入力できません。通常の準備に管理者権限は不要です。

## 使い方

### キーを押している間だけ録音する（PTT）

1. 入力したいアプリの文字入力欄を選びます。
2. 設定したキーを押したまま話します。初期候補は **F12** です。
3. キーを離すと、認識した文章を入力します。キーの組み合わせを使う場合は、修飾キーも離してください。

1回の録音は最大60秒です。認識中は入力欄を切り替えずに待ってください。

### 声を検知して録音する（自動入力）

1. 設定で自動入力を有効にし、切替キーを指定します。
2. 入力欄を選び、切替キーで自動入力を ON にします。
3. 表示が `ARMED` になってから話します。話し終えて無音が続くと、認識した文章を入力します。無音の待機時間は初期設定で800msです。
4. 終了するときは、切替キーでもう一度 OFF にします。

AUTO の ON／OFF が切り替わると、Windows 通知でお知らせします。

1回の録音は最大30秒です。入力欄の変更、自動入力の OFF、PTT の開始で、未確定の結果は破棄されます。設定の保存後とアプリの再起動後は、自動入力が OFF になります。

認識中はマイクの待機を止めるため、その間に話した音声は取得されません。

### 設定画面と終了

設定画面を閉じると、通知領域に常駐します。設定を再表示するにはアイコンをダブルクリックしてください。アプリを終了するには、通知領域のメニューから **Exit** を選びます。

### Windows ログイン時の自動起動

設定画面の **Windows ログイン時に自動起動する** にチェックを入れ、**設定を保存** を押します。次回から現在のユーザーのログイン時にトレイへ常駐します。解除するときはチェックを外して保存してください。初期状態は無効で、管理者権限は不要です。

アプリのフォルダーを移動した場合は、移動先で起動してチェックを入れた状態で再保存してください。削除する前にはチェックを外して保存してください。モデルの準備や設定の確認が必要な場合は、自動起動時にも設定画面が開きます。Windows のスタートアップ設定で無効にした場合は、そちらでも有効に戻してください。

### 入力方式とキー設定

- 標準は文字を直接入力する方式です。うまく入力できないアプリでは、設定でクリップボード経由の貼り付け方式を選択できます。
- 入力直前に IME を OFF にし、その状態を維持します。
- キーを2回押す操作は、自動入力の切替にのみ使用できます。
- Esc、Windows キー、Alt+Tab、Ctrl+Alt+Delete は指定できません。JIS 英数など、キーを離した通知を取得できないキーにも対応していません。

## モデルと設定の保存先

モデルは自動取得されるため、通常はモデルフォルダーの変更は不要です。対応するモデルを既に持っている場合は、設定画面で保存先を指定できます。認識言語は日本語に固定しています。

| 内容 | 保存先 |
|---|---|
| モデルと、そのライセンス・出典 | `%LOCALAPPDATA%\sensevoice-input\models` |
| GPU 用ファイルとライセンス文書 | `%LOCALAPPDATA%\sensevoice-input\cuda-runtime` |
| 設定 | `%LOCALAPPDATA%\SenseVoiceInput\settings.json` |
| 診断ログ | `%LOCALAPPDATA%\SenseVoiceInput\diagnostic.log` |

旧 SenseVoice 版から更新した場合は、マイクとキー設定を引き継いで Whisper に移行します。案内を確認して保存してください。旧 Caps Lock 専用設定は、キーの再設定が必要です。不正なキー設定は無効化されます。

## 困ったとき・利用上の注意

- **準備に失敗する場合:** 設定画面の理由を確認し、「モデル・GPUの準備を再試行」を選んでください。完了済みの検証済みファイルは再利用します。
- **GPU を初期化できない場合:** NVIDIA ドライバーを更新して再起動するか、Execution Provider を CPU に変更して保存してください。CPU への自動切替は行いません。
- **文字が入力されない場合:** 入力欄と入力方式を確認してください。管理者権限のアプリ、UAC 画面、独自の入力処理を使うアプリなどでは入力できない場合があります。失敗した入力を自動で再送することはありません。
- **貼り付け方式を使う場合:** 元のクリップボードを退避・復元します。退避できなければ入力を中止し、途中で別のコピー操作があれば復元しません。復元までの待機時間は初期設定で1500msです。
- **認識結果について:** 初回のモデル読み込みには時間がかかります。環境音の誤検知や、話していない内容が出力されることもあるため、入力結果を確認してください。長い発話の区切りでは認識精度が落ちる場合があります。
- 翻訳、話者の区別、専門用語辞書、話しながら逐次文字を表示する機能には対応していません。

## プライバシー

音声認識は端末内で行います。通常の診断ログには処理時間やエラーの分類を記録し、発話本文・録音・例外メッセージは記録しません。

直接入力方式ではクリップボードに触れません。貼り付け方式では履歴・同期の除外指定を付けますが、第三者アプリによるクリップボードの扱いまでは制御できません。
