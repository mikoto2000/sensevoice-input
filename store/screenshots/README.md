# Store スクリーンショット

このフォルダーへ公開対象バージョンの実画面を保存します。現時点では撮影未実施です。UI の再現画像やモックを実画面として提出しません。

Desktop の要件は PNG、1366×768 以上、1枚50 MB以下。最低1枚が必要で、4枚以上を推奨します。例として1920×1080のデスクトップを使い、アプリと入力先が読みやすい配置で撮影してください。

| ファイル名 | 内容 | キャプション案 |
|---|---|---|
| `01-first-run.png` | 初回案内と CPU の選択 | GPU がない PC でも、CPU で日本語音声入力を開始できます。 |
| `02-ptt.png` | Notepad への実際の認識結果と状態表示 | キーを押して話し、離すと認識した文章を入力します。 |
| `03-auto-input.png` | 自動入力の設定と状態 | 発話を検知し、無音が続いたところで文章を入力します。 |
| `04-settings.png` | キー・認識方式・入力方式の設定 | キーや入力方式を、自分の使い方に合わせて選べます。 |

個人情報のない Windows テストアカウントで、無害なサンプル文章を使います。マイク名、モデルパス、通知、他アプリ、クリップボードに個人情報が写っていないか確認します。キャプションは各200文字以内です。画像に宣伝文や余分なロゴを重ねません。

出典: [Microsoft の画像要件](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msix/screenshots-and-images)
