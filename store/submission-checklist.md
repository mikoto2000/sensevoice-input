# Store 提出チェックリスト

実施した項目にチェックを付け、検証環境・日付・証跡を記録します。生成 MSIX ができたことと、Store 審査の合格は別です。

## アカウントと公開情報

- [ ] 開発者アカウントの登録・本人／組織情報確認を完了
- [ ] アプリ名を予約し、Product identity を `store-config.json` へ転記
- [ ] 価格（無料を含む）・公開地域・公開日を決定
- [ ] 日本語の掲載文・カテゴリ・キーワードを確認
- [ ] 年齢区分の質問票に実際の機能に基づいて回答（区分を推測して入力しない）
- [ ] 発行者と連絡先をポリシーへ記載し、ログイン不要の HTTPS URL で公開
- [ ] サポート連絡先を確認し、Partner Center にメールまたはサポート URL を登録
- [ ] 公開版の実画面を PNG で撮影し、説明文と挙動が一致することを確認

## パッケージと実装

- [x] MSIX の `StartupTask` と設定画面を連携。ZIP 版は既存レジストリ方式を維持
- [ ] インストールした MSIX で、有効化・無効化、OS 側の無効化、再ログイン、更新後を確認
- [ ] Name / Publisher / DisplayName が予約情報と一致
- [ ] x64、Windows.Desktop、最小 OS、バージョンを確認。4桁目は 0
- [ ] `runFullTrust` の用途を審査メモに記載し、提出画面の質問に回答
- [ ] .NET 同梱の自己完結型として publish、.NET 未導入環境で起動確認
- [ ] 使用する .NET runtime の LICENSE / ThirdPartyNotices を同梱
- [ ] 既存 `LICENSE` / `THIRD_PARTY_NOTICES.md` / `licenses/` を同梱
- [ ] アイコンがスタートメニュー・検索・Store で読みやすい
- [ ] 発行パッケージにモデル、不要な NVIDIA DLL、秘密情報、テストデータが混入していない
- [ ] Windows App Certification Kit（WACK）を実行し、結果を保存・問題を解消

## クリーン環境の受け入れ検証

- [ ] NVIDIA GPU のない Windows 11 x64 で CPU 初回起動
- [ ] 設定未作成時だけ初回案内が出る。保存後の再起動で消える
- [ ] モデル取得の進捗、中止、再試行、ネットワーク切断、空き容量不足
- [ ] MSIX の実保存先、モデル・ログのアクセス権と削除方法を確認しポリシーに反映
- [ ] マイク未接続・アクセス拒否・抜き差し時の案内
- [ ] 実発話から Notepad / ブラウザー / エディターへの PTT と自動入力
- [ ] 認識中の入力先変更・取消・終了で誤入力しない
- [ ] クリップボード退避・復元と途中のコピー操作
- [ ] GPU 検出失敗、NVIDIA 条件への不同意、CUDA 実認識
- [ ] 認識本文・録音が通常ログに残らないことを確認
- [ ] 常駐中の更新・終了・アンインストール。再インストール時のデータの扱い
- [ ] 100% / 150% / 200% 表示、キーボード操作、スクリーンリーダーで設定操作
- [ ] CPU 時間、RAM、CUDA の GPU メモリ・モデル取得を含むディスク容量を実測し必要条件を掲載文へ反映
