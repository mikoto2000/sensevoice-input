発行者: mikoto2000

施行日: 2026年9月24日

## このポリシーについて

mikoto2000（以下「発行者」）は、Windows 向け日本語音声入力アプリ「SenseVoice Input」（以下「本アプリ」）で取り扱う情報について、以下のとおり説明します。

本アプリの音声認識は利用者の PC 内で行います。利用者登録は不要で、広告配信や利用状況の解析を目的とする情報の自動送信機能はありません。モデルなどのダウンロード時には外部サービスと通信します。また、利用者がメールで問い合わせを行った場合は、発行者がそのメールを受け取ります。

## 音声と認識結果

SenseVoice Input は、マイクから取得した音声を端末内で処理し、日本語の文章を認識します。Push-to-Talk では設定したキーを押している間に録音します。自動入力を有効にすると、動作条件を満たす間、マイクで発話を待ち受けます。自動入力をオフにするかアプリを終了すると待ち受けを停止します。

音声と認識結果は、音声認識と文章の入力のためにメモリ上で一時的に扱います。本アプリには、録音・認識結果を発行者や音声認識サービスのサーバーへ自動送信する機能はありません。録音ファイルや認識結果の履歴を本アプリが保存する機能もありません。

認識結果は利用者が選んだ入力先アプリへ渡されます。入力先での保存・同期・送信には、そのアプリやサービスの設定とポリシーが適用されます。

## キー操作と入力先の確認

音声入力の開始・停止や設定するキーを判定するため、他のアプリを操作している間も、アプリの動作中はキーの押下・解放を確認します。設定した入力キーは保存しますが、キー操作の履歴をファイルへ記録したり、外部へ送信したりする機能はありません。

誤った入力先への入力を避けるため、前面ウィンドウと、必要に応じてフォーカス中の要素が編集可能か、その要素の識別情報を確認します。この確認で入力欄の本文を読み取ることはありません。

## クリップボード

標準の直接入力方式ではクリップボードに触れません。貼り付け方式を選んだ場合は、元のクリップボード内容を一時的にメモリへ退避し、認識結果をコピーして貼り付けた後、条件が整っていれば元の内容を復元します。退避できない場合は入力を中止し、途中に別のコピー操作がある場合は上書き復元しません。

認識結果には Windows のクリップボード履歴・同期からの除外指定を付けます。ただし、第三者アプリによる読み取りや管理までは制御できません。

## 保存する設定と診断情報

選択したマイクの識別子、入力キー、認識方式、モデルの保存先などを端末内に保存します。診断ログには日時、処理の開始・終了、処理時間、エラーの種類やスタック情報などを記録します。通常のログには録音・発話本文・例外メッセージを記録しません。ログは約1 MBを超えると前世代へ切り替えます。

設定やダウンロード済みファイルは、変更または削除するまで端末内に残ります。診断ログは現在のファイルと前世代のファイルを保持し、切り替え時に古い前世代を置き換えます。一定の日数による自動削除は行いません。

開発・調査用の環境変数 `WHISPER_PROFILE_DIR` を利用者が設定した場合に限り、追加の演算・処理時間などの診断情報を指定先へ保存します。この診断情報も本アプリから自動送信しません。

アプリから設定・診断ログを発行者へ自動送信する機能はありません。利用者が問い合わせ時に情報を送付する場合は、内容を確認し、機密情報や他者の個人情報を含めないでください。

## ダウンロード時の通信

必要なモデルを Hugging Face、GitHub および配信先の CDN から HTTPS で取得します。CUDA を選択して GPU 用ファイルが不足している場合は、NVIDIA の利用条件への同意後に NVIDIA の配信先から取得します。CPU では GPU 用ファイルを取得しません。

ダウンロード先には通信に必要な IP アドレスやリクエスト情報が伝わります。配信サービスによる情報の扱いは各サービスのポリシーに従います。取得したモデル・GPU 用ファイル・ライセンス文書・GPU 用アーカイブは端末内に保存されます。

- [Hugging Face](https://huggingface.co/privacy)
- [GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
- [NVIDIA](https://www.nvidia.com/en-us/about-nvidia/privacy-policy/)

Microsoft Store と Windows によるインストール、更新、診断などの処理には [Microsoft のプライバシーステートメント](https://www.microsoft.com/privacy/privacystatement) と利用者の Windows 設定が適用されます。

## 情報の保護

モデル・GPU 用ファイルの取得には HTTPS を使用します。設定や診断ログは利用者の Windows ユーザーフォルダー内に保存し、Windows のアクセス制御に従います。これらのファイルを本アプリ独自の方式で暗号化する機能はありません。利用者が別の保存先を指定した場合、その場所のアクセス権や同期設定が適用されます。

## 利用者による管理と削除

設定画面でマイク、入力方式、認識方式、自動入力の有効・無効を変更できます。Windows のマイク設定でもデスクトップアプリのアクセスを管理できます。

アプリを終了したうえで、設定・ログ・ダウンロード済みモデルなどを削除できます。通常の保存先は `%LOCALAPPDATA%\SenseVoiceInput` と `%LOCALAPPDATA%\sensevoice-input` です。MSIX 版では Windows のパッケージ管理によって保存先がリダイレクトされる場合があります。独自に指定したモデルの保存先や外部のキャッシュがアンインストール時に削除されるとは限りません。入力先アプリに渡った文章や第三者アプリが取得したクリップボード内容は、本アプリから削除できません。
