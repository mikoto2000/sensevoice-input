## 表示名

SenseVoice Input

## 短い紹介

日本語の音声を、この PC 内で文字に。キーを押して話す入力と、声を検知する自動入力に対応。

## 説明

SenseVoice Input は、Windows の文字入力欄に日本語の音声認識結果を入力するアプリです。

設定したキーを押しながら話し、離すと文章を入力できます。自動入力を有効にすると、声を検知して録音し、無音が続いたところで文章を入力します。

音声認識には Whisper、発話の検知には Silero VAD を使用します。必要なモデルの初回ダウンロード後は、インターネットに接続せず利用できます。音声認識のために録音や認識結果をサーバーへ送信する機能はありません。

初期設定は CPU です。NVIDIA GPU がない PC でも利用できます。初回画面に CPU／CUDA の案内を表示します。対応する NVIDIA GPU とドライバーがあれば、CUDA を選択して GPU を利用できます。

通常は文字を直接入力します。入力先との相性に応じて、クリップボードを使う貼り付け方式も選べます。画面を閉じると通知領域に常駐し、アイコンから設定を開けます。

【必要なもの】
・Windows 11 の x64 環境とマイク
・初回のモデル取得に必要なインターネット接続と空き容量（Whisper モデルは約1.62 GB。アプリ本体や GPU 用ファイルは別途容量を使用）
・CUDA 使用時は CUDA 13 対応の NVIDIA GPU・ドライバー。GPU 用ファイルの追加取得には NVIDIA の利用条件への同意が必要です。

【ご利用にあたって】
・認識言語は日本語です。CPU では認識に時間がかかる場合があります。
・PTT は1回最大60秒、自動入力は1回最大30秒です。認識中の発話は取得しません。
・管理者権限で動くアプリ、UAC 画面、独自の入力処理を持つアプリなどでは入力できない場合があります。
・認識結果には誤りが含まれる場合があります。入力した文章をご確認ください。
・話しながら逐次文字を表示する機能、翻訳、話者識別には対応していません。
・初回ダウンロード先への接続情報やクリップボードの扱いはプライバシーポリシーをご確認ください。

## 主な機能

- キーを押している間だけ録音する Push-to-Talk
- 発話検知と無音判定による自動入力
- 端末内での日本語音声認識
- CPU と NVIDIA CUDA の選択
- 任意の入力キー・キーの組み合わせの設定
- 直接入力とクリップボード貼り付けの切り替え
